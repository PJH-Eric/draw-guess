# 你畫我猜 接力模式實作計畫書

2026-11-19

## 目標

在你畫我猜（`C:\Eric\AI Agent\draw-guess`）新增只限線上的「接力模式」：每題一人當猜題者，其餘玩家投票選題後輪流接力作畫，猜題者隨時可猜。首頁與一般模式分開入口，GA4 以 `mode=relay` 與虛擬路徑 `/relay` 區分，SEO 只更新主頁說明。一般模式的規則與行為維持不變。

## 規則定案

介面上的模式名稱一律是「接力模式」，英文 Relay，簡中 接力模式。

| 項目 | 規則 |
| --- | --- |
| 入口 | 首頁分「一般模式」與「接力模式」兩個入口；接力只有線上，進入接力大廳只列接力房 |
| 大廳聊天室 | 與一般大廳共用同一個頻道；開房公告標明是接力房 |
| 人數 | 3–8 人；遊戲中人數低於 3 人就直接結束進結算 |
| 開房設定 | 每人當猜題者 1–5 次（預設 1）；每棒作畫 7／12／17 秒（預設 12）；難度預設「混合」、種類沿用一般模式 |
| 猜題者順序 | 照座位順序輪流 |
| 中途進房 | 先觀戰，下一題加入接力順序，並補排他當猜題者的輪次 |
| 選題 | 畫家從 4 個候選題投票，限時 10 秒；全部投完提前開始；平手時從同票題目隨機選，沒人投就隨機；只顯示票數、不顯示誰投哪題 |
| 開局 | 每題選完先倒數「3、2、1、開始！」 |
| 接力順序 | 每題重新隨機，三圈沿用同一順序；畫面一直顯示接力順序，標示「正在畫」「下一棒」 |
| 每一棒 | 一定畫滿秒數、不能提早交棒；工具完全不設限制，可擦掉或清空別人的畫，復原收回畫布上最後一筆 |
| 換棒 | 中間 3 秒緩衝、畫布鎖住；緩衝一開始對下一棒震動＋音效，大字顯示「換你畫！」 |
| 圈數 | 每題最多接力三圈；最後一棒後也有 3 秒緩衝，之後才公布答案 |
| 猜題 | 猜題者隨時可猜（含緩衝），次數不限；猜錯內容大家都看得到；「很接近」只提示猜題者；畫家看得到「輸入中…」 |
| 放棄 | 猜題者有「放棄」按鈕，按下即公布答案、這題沒人得分 |
| 計分 | 第一棒 300、最後一棒 100，中間每棒平均遞減；猜題者與當下作畫者同分；緩衝中猜中算上一棒；接力中不顯示這棒值多少分 |
| 提示 | 猜題者自己按，依序字數 → 種類 → 揭一個字；每用一張，之後得分再打六折（作畫者一起降） |
| 聊天 | 畫家之間可聊天，猜題者看不到；觀戰者看得到答案 |
| 表情互動 | 沒在畫的畫家可對當下作畫者丟「加油／笑死／崩潰」，猜題者看不到 |
| 公布答案 | 停留 7 秒，只顯示完成圖，可對整張圖按愛心／大笑／拍手 |
| 斷線 | 猜題者斷線，這題直接公布答案；輪到的畫家斷線，跳過換下一位 |
| 結算 | 照總分排名，頒「神猜手」「接力王」「關鍵一筆」；畫廊放每題完成圖並列出參與畫家 |
| GA4 | 事件名稱不變，接力房帶 `mode=relay`；接力大廳與接力房送虛擬路徑 `/relay` 的 page_view |
| SEO | 不另開頁面，只更新主頁三語系標題、描述與模式列表 |

獎項定義：

- 神猜手：當猜題者時拿最多分的人
- 接力王：當畫家時拿最多分的人
- 關鍵一筆：最多題是在他那一棒（或那段緩衝）被猜中的人

## 實作步驟

分六個階段，每階段驗證通過就在本機 commit 一次（繁中 Conventional Commits，不 push）。

1. **規則核心**（`feat(relay): 新增接力模式規則核心`）
    1. 從 `rules.js` 抽出共用工具，一般模式行為不變。
    2. 新增 `relay-rules.js`：`createState`、`start`、`vote`、`tick`、`stroke`／`undo`／`clear`、`guess`、`useHint`、`giveUp`、`removePlayer`、`addPlayer`、`finish`、`toPublic`。
    3. 所有時間推進都由 `tick(now)` 決定，種子亂數決定候選題、平手抽選與接力順序，可重播。
    4. 新增 `tests/relay.js`，掛進 `npm test`。
2. **伺服器房間**（`feat(relay): 線上房間支援接力模式`）
    1. `Room` 加 `mode` 與接力設定，`setSettings` 驗證 1–5 次、每棒 7／12／17 秒。
    2. 各遊戲行動依模式分派到 `Rules` 或 `RelayRules`；人數低於 3 人結束對局。
    3. `viewFor` 依角色給視圖：猜題者看不到答案、候選題、畫家聊天與表情。
    4. `server.js` 加新事件；房間列表與大廳訂閱依模式分開。
    5. `scripts/online-check.js` 加三客戶端接力對局。
3. **首頁入口、大廳與房間設定**（`feat(relay): 新增接力模式入口與大廳`）
    1. 首頁「接力模式」按鈕、接力大廳、開房與房間設定。
    2. 三語系字串，`npm run build` 重新產生語系拆檔。
4. **遊戲中畫面**（`feat(relay): 接力對局畫面`）
    1. 投票卡（票數、倒數）、3、2、1 倒數、接力順序列、「換你畫！」大字與震動音效。
    2. 猜題者的提示與放棄按鈕、「輸入中…」、畫家表情列。
    3. 公布答案、結算獎項、畫廊與結算分享圖。
5. **RWD 與 GA4、SEO**（`feat(relay): 接力版面 RWD 與數據標示`）
    1. 手機直／橫向、平板、桌機版面，英文版一併檢查。
    2. `analytics.js` 加 `mode=relay` 與 `/relay` page_view。
    3. 更新 `seo.config.json`、`seo.gameplay.json`、主頁靜態說明與 `README.md`。
6. **最後確認**（有修正才 commit）
    1. 用 loop-engineering 流程巡檢全部畫面與完整對局，一般模式也要完整玩一局確認沒變。
    2. 截圖給你看，清除測試殘留檔。

**`public/js/relay-rules.js`：常數與階段**

```js
var CONST = {
  MIN_PLAYERS: 3,
  CHOICES: 4,
  VOTE_MS: 10000,
  COUNTDOWN_MS: 3000,
  HANDOFF_MS: 3000,
  LAPS: 3,
  REVEAL_MS: 7000,
  BATON_SEC: [7, 12, 17],
  GUESS_ROUNDS_MAX: 5,
  SCORE_FIRST: 300,
  SCORE_LAST: 100,
  HINT_FACTOR: 0.6
};
// voting → countdown → drawing ⇄ handoff → reveal →（下一位猜題者）→ over
var PHASES = ['voting', 'countdown', 'drawing', 'handoff', 'reveal', 'over'];
```

**每棒分數與提示打折**

```js
/** 第 batonNo 棒（0 起算），共 total 棒：300 平均降到 100，再乘上提示折扣 */
function batonPoints(batonNo, total, hintsUsed) {
  var base = total <= 1 ? CONST.SCORE_FIRST :
    CONST.SCORE_FIRST - (CONST.SCORE_FIRST - CONST.SCORE_LAST) * batonNo / (total - 1);
  return Math.round(base * Math.pow(CONST.HINT_FACTOR, hintsUsed));
}
```

**緩衝中猜中算上一棒**

```js
function guess(state, playerId, text, now) {
  if (playerId !== state.guesserId) return err('srv.err.relayNotGuesser', 'forbidden');
  if (['drawing', 'handoff'].indexOf(state.phase) < 0) return err('srv.err.notGuessTime', 'phase');
  var verdict = Words.match(word(state), text);
  if (verdict !== 'hit') { state.wrong.push({ text: text, at: now }); return ok({ verdict: verdict }); }
  // handoff 時 batonNo 仍指向剛畫完的那一棒
  var drawerId = state.order[state.batonNo % state.order.length];
  var pts = batonPoints(state.batonNo, state.order.length * CONST.LAPS, state.hints);
  credit(state, playerId, pts, 'guess');
  credit(state, drawerId, pts, 'baton');
  return endQuestion(state, now, 'hit', drawerId);
}
```

**投票：全部投完提前開始、平手隨機**

```js
function settleVote(state, now) {
  var tally = state.choices.map(function (id) { return countVotes(state, id); });
  var best = Math.max.apply(null, tally);
  var top = state.choices.filter(function (_, i) { return tally[i] === best; });
  var rng = RNG.createRng(state.seed + ':vote:' + state.questionNo);
  state.wordId = top[Math.floor(rng() * top.length)];
  state.phase = 'countdown';
  state.phaseEndsAt = now + CONST.COUNTDOWN_MS;
}
```

## 驗證方式

- **規則單元測試**（`tests/relay.js`）：投票提前開始、平手抽選、沒人投隨機；接力順序與三圈上限；緩衝中猜中算上一棒、最後一棒緩衝；300→100 遞減與提示六折；放棄；猜題者斷線、當棒畫家斷線、低於 3 人結束；中途加入補排；三個獎項；`toPublic` 不外洩答案給猜題者。
- **一般模式不變**：現有 `npm test` 全數通過。
- **線上測試**（`npm run test:online`）：三個客戶端完整玩一局接力，檢查猜題者收到的視圖與事件裡沒有答案、候選題、畫家聊天；一般大廳看不到接力房。
- **瀏覽器巡檢**（`scripts/browser-check.js`）：接力大廳、房間設定、投票、各角色作畫中、換棒、公布、結算，8 種尺寸與英文版截圖並人工檢視。
- **建置檢查**：`npm run build` 後語系拆檔與靜態檔版本參數是最新的。
- **GA4**：在瀏覽器的 dataLayer 確認接力事件帶 `mode=relay`、page_view 路徑為 `/relay`。
- **SEO**：建置後主頁 meta 與結構化資料包含「接力模式」。
- **手動試玩**：三個分頁實際玩一局、再來一局。
