# 你畫我猜 畫圖傳話（Beta）實作計畫書

2026-11-20

## 目標

在你畫我猜（`C:\Eric\AI Agent\draw-guess`）新增只限線上的「畫圖傳話（Beta）」：開頭的人選題並作畫，下一個人只看上一張畫、照著再畫一張，一路傳下去，最後一個人只看上一張畫猜答案，然後一次揭曉整串，看題目怎麼走樣。最後猜對時，整串的人依順序遞減得分。首頁有獨立入口與大廳，GA4 以 `mode=telephone` 與虛擬路徑 `/telephone` 區分，SEO 只更新主頁說明。其他模式的行為維持不變。

這個模式取代原本規劃的「你出我畫他猜（Beta）」（3 人 A 選 B 畫 C 猜），那份計畫書已刪除；首頁規劃為一般、接力模式（Beta）、畫圖傳話（Beta）三個入口。

建議排在接力模式（Beta）之後實作：房間的 `mode` 分派、首頁多模式入口、依模式分開的大廳列表、GA4 `mode` 白名單都會在接力模式先做好，這裡直接沿用。

## 規則定案

介面上的模式名稱一律是「畫圖傳話（Beta）」，英文 Draw Telephone (Beta)，簡中 画图传话（Beta）。

| 項目 | 規則 |
| --- | --- |
| 入口 | 首頁「畫圖傳話（Beta）」按鈕，有自己的大廳，只列這種房間；大廳聊天室與其他大廳共用，開房公告標明模式 |
| 人數 | 3–5 人；滿 5 人後其他人只能觀戰 |
| 開房設定 | 每張畫 30／45／60 秒（預設 45 秒）；最後猜答案 20／25／30 秒（預設 25 秒）；輪次 1–3（預設 1 輪；每輪傳一串、輪結束就揭曉）；難度與種類沿用一般模式 |
| 開頭 | 第 1 輪由座位第一位開頭，之後每輪換下一位開頭 |
| 選題 | 開頭的人從題庫 3 個候選挑 1 個，限時 15 秒，沒選就隨機 |
| 傳話順序 | 從開頭的人起照座位往下，每人輪一次：A 看題目作畫 → B 只看 A 的畫再畫 → C 只看 B 的畫再畫 → … → 最後一個人只看上一張畫猜答案，寫完就揭曉 |
| 換手 | 每次換人先有 5 秒換手倒數：輪到的人先看上一張畫（開頭的人看題目），倒數完才能動手，不算在作畫或猜答案秒數裡 |
| 每一步 | 作畫照開房設定的秒數，只看得到上一張畫（A 看題目）；最後一人猜答案照開房設定的秒數，答案最長 40 字 |
| 作畫工具 | 跟一般模式一樣 |
| 照畫 | 照畫的人只有換手那 5 秒看得到上一張畫，開始作畫後就收起來，憑記憶畫；畫完揭曉時才再看到 |
| 等待中 | 作畫階段：還沒輪到的人只看得到「輪到誰、還剩幾秒」，看不到任何畫；前面已經畫完的人與下一位可以即時看目前這一格作畫（例：ABCD，A 畫只有 B 看得到；B 畫 A、C 看得到；C 畫 A、B、D 看得到）；觀戰者全部都看得到（題目與每一格作畫過程） |
| 中間的人猜題 | 不是開頭也不是最後的人，交出畫之後可以一直猜原本的題目直到猜中：猜中 50 分、每猜錯一次 -10（最低 10），不能用提示；猜錯只有自己知道，猜中大家看到「某某猜中了」（不含題目）；分數跟整串分開算；已猜中的人不會被找去代猜 |
| 等最後一人猜時 | 其他玩家可以翻看這一輪所有人的畫，看不到題目與猜的人正在打的字（觀戰者看得到題目，但也看不到正在打的字）；猜的人仍只看得到上一張畫與自己開的提示 |
| 聊天 | 傳話進行中關閉房間聊天（輸入框隱藏、伺服器也拒收），避免暴雷；開局前的等待室與揭曉、結算時可以聊 |
| 逾時 | 時間到就送出目前內容：畫到一半照傳；答案沒寫就傳「（沒寫）」 |
| 斷線 | 輪到的人斷線直接跳過，把上一張畫交給下一位（最後一人斷線就由前一位改猜）；剩不到 3 人就結束這一場進結算 |
| 中途進房 | 先觀戰，下一輪起加入傳話順序（未滿 5 人時） |
| 揭曉 | 一次列出整串（題目 → 每個人的畫 → 最後的答案），內容多時用自訂捲軸捲動；每一格可按愛心／大笑 |
| 提示 | 由最後猜的人主動使用，可以用很多張；猜答案的倒數不會暫停。一般提示照順序：字數 → 種類 → 揭一個字，每張讓這一輪得分打六折 |
| 偷看前面的畫 | 另一種提示：猜的人可以點開前面任何一位的畫（自己本來就看得到上一張）。看越前面的畫扣越多：第一張 ×0.3，越往後越接近 ×0.7（平均分配）；可以看很多張，倍數相乘 |
| 計分 | 最後一人猜對時，這一輪全部的人都得分，依傳話順序遞減：第一位（選題並畫）300 分，之後每人平均遞減，最後猜的人 100 分；再乘上這一輪用過的所有提示倍數（一起扣，不只扣猜的人）；猜錯或沒寫，這一輪全部 0 分；被跳過的人不得分 |
| 結算 | 照總分排名；另頒「最好笑」（按讚最多那一格的作者），沒有人按讚就不頒 |
| GA4 | 事件名稱不變，帶 `mode=telephone`；這個模式的大廳與房間送虛擬路徑 `/telephone` 的 page_view |
| SEO | 不另開頁面，只更新主頁三語系標題、描述與模式列表 |

格子數量範例：

| 人數 | 一串的格子 | 最後一格 |
| --- | --- | --- |
| 3 人 | A 選題並畫 → B 照畫 | C 猜 |
| 4 人 | A 選題並畫 → B、C 照畫 | D 猜 |
| 5 人 | A 選題並畫 → B、C、D 照畫 | E 猜 |

只有最後一個人寫文字，猜對與否就看他的答案和原題比對的結果（比對方式跟一般模式相同）。

得分範例（猜對時）：

| 人數 | 依順序得分 |
| --- | --- |
| 3 人 | A 300、B 200、C（猜）100 |
| 4 人 | A 300、B 233、C 167、D（猜）100 |
| 5 人 | A 300、B 250、C 200、D 150、E（猜）100 |

提示扣分範例（4 人：A 畫、B 畫、C 畫、D 猜；D 本來就看得到 C 的畫，可以偷看 A 或 B 的畫）：

| D 用的提示 | 倍數 | A／B／C／D 得分 |
| --- | --- | --- |
| 沒用 | ×1 | 300／233／167／100 |
| 字數 | ×0.6 | 180／140／100／60 |
| 偷看 B 的畫 | ×0.7 | 210／163／117／70 |
| 偷看 A 的畫 | ×0.3 | 90／70／50／30 |
| 字數＋偷看 A 的畫 | ×0.18 | 54／42／30／18 |

揭曉時會標示這一輪用了哪些提示、偷看了誰的畫。

## 實作步驟

分六個階段，每階段驗證通過就在本機 commit 一次（繁中 Conventional Commits，不 push）。

1. **規則核心**（`feat(telephone): 新增畫圖傳話規則核心`）

**一串的格子與傳話順序**

```js
/** 從開頭的人起照座位排一次：前面都是作畫（看上一張畫照畫），最後一人猜答案 */
function buildChain(state, starterIdx, wordId) {
  var seats = state.seats, n = seats.length, cells = [];
  for (var i = 0; i < n; i++) {
    cells.push({
      authorId: seats[(starterIdx + i) % n],
      kind: i === n - 1 ? 'write' : 'draw',
      strokes: [], text: '', skipped: false
    });
  }
  return { wordId: wordId, cells: cells, reactions: {} };
}
```

**提示倍數**

```js
/** 偷看第 idx 張畫（0 = 第一張）；可偷看的是最後猜的人看不到的那幾張（共 peekable 張） */
function peekFactor(idx, peekable) {
  return peekable <= 1 ? 0.3 : 0.3 + 0.4 * idx / (peekable - 1);   // 越前面越低
}
function hintFactor(chain) {
  var f = Math.pow(0.6, chain.hints.basic);                         // 字數／種類／揭字
  chain.hints.peeks.forEach(function (idx) { f *= peekFactor(idx, chain.cells.length - 2); });
  return f;
}
```

**猜對時依順序遞減得分**

```js
/** 最後一人猜對：第一位 300，平均遞減到最後猜的人 100，再乘提示倍數；被跳過的人不得分 */
function scoreChain(state, chain) {
  var hit = Words.match(Words.byId(chain.wordId, state.lang), lastCell(chain).text) === 'hit';
  var cells = chain.cells, n = cells.length, f = hintFactor(chain);
  cells.forEach(function (cell, i) {
    var pts = !hit || cell.skipped ? 0 : Math.round((300 - 200 * i / (n - 1)) * f);
    cell.points = pts;
    if (pts) player(state, cell.authorId).score += pts;
  });
  chain.hit = hit;
}
```

**逾時送出與斷線跳過**

```js
function tick(state, now) {
  if (state.phase !== 'step' || now < state.stepEndsAt) return ok({ changed: false });
  var cell = currentCell(state);
  if (cell.kind === 'write' && !cell.text) cell.text = '';   // 揭曉時顯示「（沒寫）」
  return advance(state, now);                                // 畫到一半照傳
}

function advance(state, now) {
  state.stepNo += 1;
  while (state.stepNo < chainOf(state).cells.length && isAway(state, currentCell(state).authorId)) {
    currentCell(state).skipped = true;                       // 斷線的人跳過
    state.stepNo += 1;
  }
  if (state.stepNo >= chainOf(state).cells.length) return reveal(state, now);
  var c = currentCell(state);
  state.stepEndsAt = now + (c.kind === 'draw' ? state.drawSec * 1000 : state.guessSec * 1000);
  return ok({ changed: true });
}
```

**只給輪到的人上一格**

```js
function toPublic(state, viewerId) {
  var view = { phase: state.phase, turnId: currentCell(state).authorId, endsAt: state.stepEndsAt };
  if (state.phase === 'reveal' || state.phase === 'over') {
    view.chain = chainOf(state);                             // 揭曉後才給整串
  } else if (viewerId === view.turnId) {
    view.prev = previousVisible(state);                      // A 拿題目，其他人拿上一張畫
  } else if (currentCell(state).kind === 'write') {
    view.drawings = drawingsOnly(chainOf(state));            // 等最後一人猜：其他人翻看全部的畫，不含題目
  }
  return view;
}
```

- **線上測試**（`npm run test:online`）：四個客戶端完整玩一輪、再玩一輪；等待中的客戶端收不到畫或答案；其他大廳看不到這種房間。
- **瀏覽器巡檢**（`scripts/browser-check.js`）：大廳、房間設定、選題、作畫、照畫、猜答案、等待、揭曉、結算，8 種尺寸與英文版截圖並人工檢視。
- **建置檢查**：`npm run build` 後語系拆檔與靜態檔版本參數是最新的。
- **GA4**：dataLayer 確認事件帶 `mode=telephone`、page_view 路徑為 `/telephone`。
- **SEO**：建置後主頁 meta 與結構化資料包含「畫圖傳話（Beta）」。
- **手動試玩**：四個分頁實際玩一局、再來一局。
