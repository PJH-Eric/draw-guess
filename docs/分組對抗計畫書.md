# 你畫我猜 分組對抗（Beta）實作計畫書

2026-11-21

## 目標

在你畫我猜（`C:\Eric\AI Agent\draw-guess`）新增只限線上的「分組對抗（Beta）」：玩家在等待室自選紅隊或藍隊，兩隊輪流派一人畫，本隊先猜 30 秒，猜不出來時對手隊進入偷答階段，偷答成功就搶走分數。依總分決定哪一隊獲勝，並頒個人最佳畫家與最佳猜手。首頁有獨立入口與大廳，GA4 以 `mode=team` 與虛擬路徑 `/team` 區分，SEO 只更新主頁說明。其他模式（一般、接力、畫圖傳話）的行為維持不變。

## 規則定案

介面上的名稱一律是「分組對抗（Beta）」，英文 Team Battle (Beta)，簡中 分组对抗（Beta）。模式代號 `team`。

| 項目 | 規則 |
| --- | --- |
| 入口 | 首頁「分組對抗（Beta）」按鈕，有自己的大廳，只列這種房間；大廳聊天室與其他大廳共用，開房公告標明模式 |
| 人數 | 4–8 人，每隊至少 2 人；第 9 人起只能觀戰 |
| 分隊 | 等待室分紅隊、藍隊兩欄，玩家自己點選加入或換隊；房主可把任何人移到另一隊；兩隊人數不一樣也能開始（每隊至少 2 人即可）；開始後不能換隊 |
| 開房設定 | 本隊猜題時間 30／45／60 秒（預設 30）；偷答時間 15／20／30 秒（預設 20）；輪數 1–3（預設 1）；難度與種類沿用一般模式 |
| 出題順序 | 兩隊交替：紅、藍、紅、藍……；同隊內依加入順序輪流，每人畫一次為一輪；兩隊人數不同時，人數少的隊從頭再輪（第一輪，兩隊都畫滿「人數較多那隊的人數」次） |
| 題目 | 畫家看到題目，出題方式與時限沿用一般模式；題目只有畫家與觀戰者看得到 |
| 作畫 | 畫家在整題（本隊階段＋偷答階段）持續作畫，工具同一般模式；兩隊所有人都看得到畫的即時筆畫 |
| 本隊階段 | 開始後前 30 秒（依設定），只有畫家的隊友能輸入答案；可以一直猜，猜錯照一般模式的冷卻時間；猜中就結束這一題 |
| 偷答階段 | 本隊階段結束仍沒人猜中，對手隊進入偷答（預設 20 秒）；**對手隊整隊只有一次機會**：任何一位對手送出的第一個答案就是這一隊的答案，對了就偷分，錯了偷答立刻結束；偷答階段本隊不能再猜 |
| 提示 | 只有畫家隊友能用，字數 → 種類 → 揭一個字，每用一次本隊得分乘 0.6；已揭示的提示在偷答階段對手也看得到；偷答成功的分數不受提示影響 |
| 本隊猜中 | 本隊得 `P` 分：`P = 100 + 200 × 剩餘比例`（剩餘比例 = 本隊階段剩餘秒數 ÷ 本隊階段總秒數）× 提示倍數，四捨五入，最高 300、最低 100 以內；畫家與猜中的人各得個人分 `P`（隊分只加一次，不重複計算） |
| 偷答成功 | 對手隊得固定 150 分，偷答的那個人得個人分 150；畫家隊 0 分、畫家 0 分 |
| 沒人答對 | 兩隊都 0 分，題目揭曉後換下一題 |
| 猜錯可見度 | 本隊猜錯的答案只有本隊與觀戰者看得到；對手隊只看到「某隊猜了 N 次」，避免直接抄答案；猜中時全場顯示誰猜中與得分 |
| 每題結束 | 揭曉題目與得分約 4 秒（含畫的完整畫面），再換下一題；倒數與提示音沿用一般模式 |
| 聊天 | 題目進行中關閉房間聊天（輸入框隱藏、伺服器也拒收），避免暗示答案；等待室、每題揭曉空檔與結算時可以聊 |
| 逾時 | 畫家沒開始畫也照時間走；本隊階段與偷答階段時間到就進下一階段 |
| 斷線 | 畫家斷線超過 5 秒：這一題作廢（0 分），題目不公開，換下一題；任一隊全數斷線就立刻結束，對方隊直接獲勝；一隊剩 1 人時可以繼續，但畫家輪到同一個人 |
| 中途進房 | 先觀戰，下一輪開始前可以選隊加入（未滿 8 人時） |
| 觀戰者 | 看得到題目、所有筆畫、兩隊所有答案與提示，不能輸入 |
| 結算 | 兩隊總分高者獲勝，同分顯示平手；個人頒「最佳畫家」（讓本隊得分最多的畫家）與「最佳猜手」（個人猜中分最高），沒人得分就不頒；另列個人分排名與每題回顧（題目、畫、誰猜中、得分） |
| GA4 | 事件名稱不變，帶 `mode=team`；大廳與房間送虛擬路徑 `/team` 的 page_view |
| SEO | 不另開頁面，只更新主頁三語系標題、描述與模式列表 |

分數範例（本隊階段 30 秒）：

| 情境 | 隊分 | 個人分 |
| --- | --- | --- |
| 第 6 秒猜中、沒用提示 | 100 + 200 × 24/30 = 260 | 畫家 260、猜中者 260 |
| 第 20 秒猜中、用了 1 個提示 | (100 + 200 × 10/30) × 0.6 = 100 | 畫家 100、猜中者 100 |
| 本隊沒猜中，對手偷答成功 | 對手隊 150、畫家隊 0 | 偷答者 150 |

## 作畫時間與其他人做什麼

整題固定 `ownSec + stealSec` 秒（預設 30 + 20 = 50 秒），畫家全程作畫，不另設作畫倒數。

| 階段 | 畫家 | 畫家隊友 | 對手隊 | 觀戰者 |
| --- | --- | --- | --- | --- |
| 本隊階段（預設 30 秒） | 畫畫，看得到題目 | 即時看畫、輸入答案、用提示 | 即時看畫，輸入框鎖住，只看到「對方隊猜了 N 次」 | 看畫與題目，不能輸入 |
| 偷答階段（預設 20 秒） | 繼續畫 | 即時看畫，不能再猜 | 即時看畫，整隊只有一次輸入機會 | 同上 |

## 實作步驟

分六個階段，每階段驗證通過就在本機 commit 一次（繁中 Conventional Commits，不 push）。

1. **規則核心**（`feat(team): 新增分組對抗規則核心`）
    1. 新增 `team-rules.js`：`createState`、`setTeam`、`moveTeam`、`start`、`beginTurn`、`guess`、`hint`、`addStroke`／`undoStroke`／`clearBoard`、`tick(now,{away})`、`removePlayer`、`addPlayer`、`finish`、`toPublic`。
    2. 出題順序在 `start` 時依兩隊人數產生整串（紅藍交替、人數少的隊重輪），`beginTurn` 取下一題。
    3. 時間推進只由 `tick(now)` 決定：own → steal → turnEnd；偷答只收第一個答案。
    4. 計分函式純函式化，方便單元測試。
    5. 新增 `tests/team.js`，掛進 `npm test`。
2. **伺服器房間**（`feat(team): 線上房間支援分組對抗`）
    1. `Room` 支援 `mode:'team'` 與設定、分隊資料、房主換隊。
    2. `viewFor`、`strokeTargets` 與聊天閘門；畫家斷線作廢、一隊全斷線結束。
    3. 房間列表與大廳訂閱加 `team`；`scripts/online-check.js` 加四客戶端完整對局（含偷答成功與失敗）。
3. **首頁入口、大廳、等待室**（`feat(team): 新增分組對抗入口與等待室`）
    1. 首頁按鈕、專屬大廳、開房設定、等待室紅藍兩欄與換隊。
    2. 三語系字串，`npm run build` 重新產生語系拆檔。
4. **遊戲中畫面**（`feat(team): 分組對抗對局畫面`）
    1. 比分條、階段橫幅（本隊猜題中／偷答中）、倒數條。
    2. 畫家畫面、隊友猜題畫面（含提示）、對手隊等待畫面、偷答輸入、觀戰者畫面。
    3. 每題揭曉、結算（勝負、獎項、排名、每題回顧）、結算分享圖；題目進行中隱藏房間聊天。
5. **RWD、GA4、SEO、教學**（`feat(team): 版面 RWD 與數據標示`）
    1. 手機直／橫向、平板、桌機版面，英文版一併檢查；等待室與每題回顧使用自訂捲軸。
    2. `analytics.js` 加 `mode=team` 與 `/team` page_view。
    3. 教學（`tut.team.*`）、`seo.config.json`、`seo.gameplay.json`、主頁靜態說明與 `README.md`。
6. **最後確認**（有修正才 commit）
    1. 用 loop-engineering 流程巡檢全部畫面與完整對局；其他模式各完整玩一局確認沒變。
    2. 截圖給你看，清除測試殘留檔。

## 相關程式碼片段

狀態形狀（`public/js/team-rules.js`，示意）：

```js
// state
{
  phase: 'lobby' | 'turn' | 'turnEnd' | 'over',
  teams: { red: [playerId...], blue: [playerId...] },
  settings: { ownSec: 30, stealSec: 20, rounds: 1 },
  order: [{ team: 'red', drawer: 'p1' }, { team: 'blue', drawer: 'p3' }, ...],
  turnNo: 0,
  turn: {
    team: 'red', drawer: 'p1', word: '貓',
    stage: 'own' | 'steal',
    ownEndsAt: 0, stealEndsAt: 0,
    hints: 0, guesses: { red: 0, blue: 0 },
    stealUsed: false,
    result: null // { kind: 'own'|'steal'|'none', who, points }
  },
  score: { red: 0, blue: 0 },
  personal: { p1: { draw: 0, guess: 0 } }
}
```

計分（純函式）：

```js
function ownPoints(remainSec, ownSec, hints) {
  const base = 100 + 200 * Math.max(0, Math.min(1, remainSec / ownSec));
  return Math.round(base * Math.pow(0.6, hints));
}
const STEAL_POINTS = 150;
```

偷答只收第一個答案：

```js
function guess(state, id, text, now) {
  const t = state.turn;
  const team = teamOf(state, id);
  if (t.stage === 'own' && team === t.team && id !== t.drawer) { /* 本隊猜題 */ }
  else if (t.stage === 'steal' && team !== t.team && !t.stealUsed) {
    t.stealUsed = true;               // 整隊只有一次機會
    return matches(text, t.word) ? stealHit(state, id, now) : endTurn(state, 'none', now);
  } else return { ok: false };
}
```

`toPublic` 依角色過濾（`lib/rooms.js` 的 `viewFor` 呼叫）：

```js
// 對手隊與非畫家：不給 word；對手隊不給本隊猜錯內容，只給次數
view.word = (role === 'drawer' || role === 'spectator') ? t.word : null;
view.guessLog = (role === 'spectator' || team === t.team) ? t.guessLog : null;
view.guessCount = t.guesses;
```

聊天閘門（`lib/rooms.js`，沿用畫圖傳話的 `chatOpen`）：

```js
chatOpen() { return this.mode !== 'team' || this.state.phase !== 'turn'; }
```

## 驗證方式

- `node tests/team.js`：分隊與換隊、出題順序（含人數不同）、本隊猜中計分、提示倍數、偷答成功／失敗／逾時、沒人答對、畫家斷線作廢、一隊全斷線結束、中途進房、`toPublic` 各角色不洩漏題目與猜錯內容。
- `npm test`、`scripts/online-check.js`：四個客戶端完整一場（含偷答），再開一場。
- `scripts/team-browser-check.js`：等待室、對局各階段、每題揭曉、結算，在手機直橫向、平板直橫向、桌機截圖檢查；英文版一併看。
- 既有的 `build-locales --check`、`build-css --check`、`stamp-assets --check`、一般／接力／畫圖傳話的瀏覽器檢查全數通過。
- 手動：房主換隊、對手偷答一次機會、關閉聊天、離開與重新連線。

## 不包含項目

- 依需求不提供 SQL script。
- 依需求不提供 Migration（專案本身沒有資料庫，隊伍與分數只存在房間記憶體）。
- 不含隊內專屬聊天頻道、隊伍名稱自訂、AI 隊員、單機版；之後有需要再另外規劃。

## 待確認的假設

以下是計畫書中我替你補的細節，開始實作前可以改：

1. 偷答「對手整隊只有一次機會」（任何一位對手送出的第一個答案就是整隊的答案）。
2. 人數不同時，人數少的隊從頭再輪畫，不另外給讓分。
3. 對局中關閉房間聊天，不做隊內頻道。
4. 本隊猜錯的答案對手隊看不到，只看到猜了幾次。
5. 畫家在本隊與偷答階段都持續作畫，整題固定 `ownSec + stealSec` 秒。
